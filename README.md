# Assessor Platform — Платформа для безопасной перекрестной разметки данных

это open-source платформа для организации безопасного процесса разметки и верификации документов внутри контура компании. Проект спроектирован для ML-команд и бэк-офиса, которым необходимо качественно оцифровывать данные без риска их утечки.

---
## Проблема
При организации процесса разметки данных мы столкнулись с критическими функциональными ограничениями доступных на рынке платформ. Существующие решения не дают прозрачного контроля над процессом и качеством:
1. Слепая зона в аналитике: Нет возможности детально отслеживать работу асессоров (реальное время работы, учет простоев, частота ошибок).
2. Отсутствие Quality Assurance «из коробки»: Нет встроенных алгоритмов автоматической перекрестной проверки (cross-validation) и удобного интерфейса для арбитража конфликтов.
3. Уязвимость контента: Отсутствуют базовые механизмы защиты визуальных данных (например, водяные знаки).
4. Использование базовых инструментов (таблиц или простых форм) неизбежно приводит к неконтролируемому качеству датасетов, ошибкам случайного ввода и фроду со стороны исполнителей.

## Решение
Разработана внутренняя платформа с жесткой ролевой моделью, алгоритмом слепой перекрестной проверки, защитой от утечек и встроенным конструктором форм для масштабирования на любые типы документов.

## 🚀 Основные возможности

- **Ролевая модель:** Разделение прав на Асессоров, Администраторов и Суперадминов.
- **Рабочее место асессора:** 
  - Динамическая подгрузка полей по настраиваемым схемам типов документов.
  - Умный таймер активности (автоматическая пауза при бездействии более 30 секунд).
  - Инструменты просмотрщика (масштабирование колесиком мыши, поворот на 90°, поддержка PDF и изображений).
  - Динамические водяные знаки: Поверх просматриваемого документа накладывается полупрозрачный паттерн с ID текущего асессора. При попытке сфотографировать экран на телефон, служба безопасности легко идентифицирует источник утечки.
- **Панель администратора:**
  - Настройка процента двойной проверки (перехлест).
  - Загрузка файлов с компьютера или массовый импорт по ссылкам из CSV.
  - Конструктор форм (создание новых типов документов и полей).
  - Управление пользователями и мониторинг статистики асессоров (скорость, время, ошибки).
  - Разрешение конфликтов разметки при расхождении данных асессоров.
- **Панель суперадмина:** Резервное копирование базы данных (`.json`), восстановление из бэкапа и полный сброс системы.

## 🛠 Технологический стек

- **Бэкенд:** Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL.
- **Фронтенд:** Vue 3 (Composition / Options API), Tailwind CSS.
- **Инфраструктура:** Docker, Docker Compose.

## ⚙️ Установка и запуск

Самый простой способ запустить проект со всеми зависимостями и базой данных:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Arteemm007/data_labeling.git
   cd data_labeling
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта (рядом с docker-compose.yml) со следующим содержимым:

   ```env
   POSTGRES_USER=admin
   POSTGRES_PASSWORD=ваш_пароль
   POSTGRES_SERVER=postgres
   POSTGRES_PORT=5432
   POSTGRES_DB=assessor_db
   STORAGE_DIR=storage
   ```

3. **Запустите проект:**
   ```bash
   docker compose up --build
   ```

### 4. Запуск фронтенда
Откройте http://localhost:8000

Пароль: admin

## 🛠 Ручной запуск (для разработки)

### 1. Клонирование репозитория
```bash
git clone https://github.com/Arteemm007/data_labeling.git
cd data_labeling
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта:

```env
POSTGRES_USER=admin
POSTGRES_PASSWORD=ваш_пароль
POSTGRES_SERVER=localhost
POSTGRES_PORT=5432
POSTGRES_DB=assessor_db
STORAGE_DIR=storage
```

### 3. Запуск бэкенда
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
# Через uv (рекомендуется)

uv pip install -r requirements.txt
# Или через стандартный pip
pip install -r requirements.txt

# Применение миграций базы данных
alembic upgrade head

# Запуск сервера
uvicorn app.main:app --reload
```

### 4. Запуск фронтенда
Откройте http://localhost:8000

Пароль: admin
